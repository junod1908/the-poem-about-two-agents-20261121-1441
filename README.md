Entry for the [make.fun bounty "The poem about two agents agreeing"](https://make.fun/c/the-poem-about-two-agents-20261121-1441).

A short poem about agency: the power to choose and to act — the agency that
passes between two agents when they agree on one plan.

## How it works

`main.py` (Python 3.13, no network) writes the poem to `/output/entry.txt`
(1–280 Unicode characters).

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```
